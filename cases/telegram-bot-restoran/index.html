Проблема

Мария управляет рестораном на 60 посадочных мест. Бронирования принимали только по телефону — с 10:00 до 22:00. Администратор тратила около 3 часов в день на звонки: уточнение даты, числа гостей, предпочтений, подтверждение. Ночные брони пропадали — клиенты уходили к конкурентам.

Кроме того, администратор вела таблицу занятости в Google Sheets — два раза она случайно подтвердила одно и то же время двум разным группам.

Задача

Дать клиентам возможность бронировать столики через Telegram в любое время суток, с проверкой доступности и автоматическими подтверждениями. При этом менеджер должен видеть все брони в одном месте и получать уведомление о каждой новой.

Решение

Разработал Telegram-бота на Python + aiogram с интеграцией в Google Calendar как базой занятости. Бот показывает меню, принимает бронирование, проверяет свободные слоты в Calendar и отправляет подтверждение клиенту и алерт менеджеру.

Функции бота:

  • Просмотр меню с разделами и фотографиями блюд
  • Выбор даты и времени — бот показывает только доступные слоты из Google Calendar
  • Указание числа гостей и особых пожеланий (детское кресло, аллергии)
  • Автоматическое подтверждение с деталями бронирования
  • Напоминание за 2 часа до брони
  • Возможность отменить или перенести через бот
  • Уведомление менеджеру о каждой новой брони в отдельный чат

Технический стек

  • Python 3.11 + aiogram 3 — бот
  • Google Calendar API — хранение и проверка занятости
  • SQLite — история бронирований и профили пользователей
  • VPS + systemd — деплой без Docker (по запросу клиента)

Результат

За первые 2 недели после запуска 30% всех новых бронирований пришли через бота — в том числе 8 броней, оформленных после 22:00. Мария подсчитала, что администратор теперь тратит на звонки около 1 часа вместо 3–4 часов в день.

«Люди сами бронируют ночью и ждут подтверждения утром. Нам ничего не нужно делать — всё приходит в Telegram» — написала Мария через месяц после запуска.
