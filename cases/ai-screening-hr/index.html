Проблема

HR-агентство работало с несколькими крупными клиентами — производство, IT, торговля. Ежедневно поступало 50–200 резюме на разные вакансии. Рекрутер просматривал их вручную, тратя 5–6 часов в день только на первичный скрининг — даже не на интервью, а на отсев.

Из-за объёма часть резюме «подвисала» на несколько дней. Хорошие кандидаты уходили, потому что ответ приходил через неделю. Рекрутер выгорал от монотонной работы.

Задача

Автоматически оценивать поступающие резюме по заданным критериям для каждой вакансии, выставлять числовой score и каждое утро присылать рекрутеру дайджест топ-5 кандидатов с кратким обоснованием.

Решение

Построил систему на Python + OpenAI API. Резюме поступают на почту или загружаются вручную, парсятся из PDF/Word, анализируются GPT-4o по системному промпту с критериями вакансии.

Как работает:

  • Письмо с резюме → автоматический парсинг текста из PDF/DOCX
  • GPT-4o оценивает резюме по критериям: опыт (лет), стек, образование, гео, зарплатные ожидания
  • Каждому резюме присваивается score от 0 до 100 и краткий комментарий (2–3 предложения)
  • Резюме кешируется в Redis — повторная обработка не тратит токены
  • Ежедневно в 8:00 рекрутер получает в Telegram дайджест: топ-5 кандидатов за прошедшие сутки с score и причиной
  • Рекрутер нажимает «Подробнее» — получает полный текст резюме

Технический стек

  • Python 3.11 — основная логика
  • OpenAI API (GPT-4o) — анализ и оценка резюме
  • PyPDF2 + python-docx — парсинг документов
  • Redis — кеш обработанных резюме
  • aiogram — Telegram-бот для дайджеста
  • APScheduler — отправка дайджеста в 8:00

Результат

Рекрутер перестал тратить 6 часов на первичный скрининг. Теперь утром смотрит пятёрку лучших за день и сразу пишет им — без просмотра 200 файлов. Средний балл кандидатов на первом интервью вырос: рекрутер больше не «случайно» пропускает хороших из-за усталости.

Агентство подключило систему к двум дополнительным клиентам — она масштабируется добавлением новой вакансии с критериями в конфиг.
