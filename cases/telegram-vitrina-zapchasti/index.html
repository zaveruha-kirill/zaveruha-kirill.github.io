Проблема

Магазин автозапчастей работал как многие: клиент звонил или писал в WhatsApp, спрашивал «есть ли деталь», менеджер шёл смотреть в 1С, перезванивал. На один такой цикл уходило 10–15 минут. Менеджер тратил до 2 часов в день только на ответы «есть / нет в наличии».

Часть клиентов писала поздно вечером — ответа ждали до следующего утра и за это время успевали заказать у конкурентов онлайн.

Задача

Дать клиентам возможность самостоятельно проверить наличие детали по артикулу или названию, увидеть актуальную цену из 1С и оформить заявку прямо в Telegram — без звонка и без ожидания.

Решение

Разработал Telegram-бота на Python + aiogram с подключением к базе 1С через HTTP-API (1С публикует данные как REST-сервис). Остатки синхронизируются раз в час — клиент всегда видит актуальное наличие.

Функции бота:

  • Поиск по артикулу — точное совпадение, показывает наименование, наличие и цену
  • Поиск по названию — нечёткий поиск, выводит до 5 похожих позиций
  • Просмотр категорий товаров с фильтрацией по марке автомобиля
  • Оформление заявки: клиент указывает количество, контакт, удобное время — менеджер получает уведомление
  • Статус заявки: клиент может проверить через бота на каком этапе его заказ
  • Синхронизация с 1С каждый час: остатки и цены всегда актуальны

Технический стек

  • Python 3.11 + aiogram 3 — бот
  • 1С 8.3 REST API — данные об остатках и ценах в реальном времени
  • PostgreSQL — история заявок, профили пользователей
  • APScheduler — синхронизация с 1С раз в час
  • VPS + Docker — деплой

Результат

За первый месяц 25% всех заказов оформлялись через бота без звонка менеджеру. Появились ночные заказы — клиенты, которые раньше откладывали на утро, теперь оформляли запрос сразу. Менеджер освободил около 2 часов в день от рутинных консультаций «есть ли деталь».
