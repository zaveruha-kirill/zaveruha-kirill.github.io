Проблема

Компания по продаже строительных материалов получала большой поток заявок через WhatsApp. Менеджеры отвечали когда успевали — иногда через 2–3 часа. Часть сообщений терялась в чате. AmoCRM существовала, но заявки из WhatsApp туда не попадали — менеджер вёл параллельно и часто забывал.

По оценке руководителя отдела продаж, теряли около 15% заявок только из-за медленного ответа — клиенты уходили к конкурентам раньше, чем получали ответ.

Задача

Автоматически создавать сделку в AmoCRM при каждом входящем сообщении в WhatsApp, распределять по менеджерам и отправлять клиенту приветственное сообщение в течение 30 секунд — без участия человека.

Решение

Разработал интеграционный слой на Node.js с webhook-сервером, который слушает входящие сообщения через WhatsApp Business API и синхронизирует с AmoCRM через её REST API.

Схема работы:

  • Клиент пишет в WhatsApp → webhook получает событие
  • Система проверяет: есть ли открытая сделка от этого номера в AmoCRM
  • Если нет — создаёт новую сделку, контакт и задачу менеджеру
  • Менеджер назначается по алгоритму round-robin с учётом загруженности (кол-во открытых сделок)
  • Клиенту автоматически уходит приветственное сообщение с именем его менеджера и ожидаемым временем ответа
  • Все дальнейшие сообщения из диалога попадают в карточку сделки как комментарии

Технический стек

  • Node.js + Express — webhook-сервер
  • WhatsApp Business API (через официального провайдера) — входящие/исходящие сообщения
  • AmoCRM REST API — создание сделок, контактов, задач
  • PostgreSQL — лог событий и маппинг номеров к сделкам
  • VPS + PM2 — деплой

Результат

После запуска интеграции потери заявок прекратились — каждое сообщение фиксируется в CRM. Клиент получает ответ в течение 30 секунд (автоматическое приветствие) вместо ожидания часами. Конверсия из заявки в сделку выросла на 35% за 2 месяца — руководитель связывает это именно со скоростью первого контакта.
