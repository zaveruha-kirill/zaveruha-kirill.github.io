Проблема

Сеть автомоек в нескольких районах города. Владелец Игорь случайно узнал о негативном отзыве на 2ГИС — клиент пожаловался на грязные коврики, а отзыв провисел 10 дней без ответа. За это время потенциальные клиенты читали его и уходили к конкурентам.

Игорь не мог мониторить 2ГИС и Яндекс.Карты вручную каждый день по 4 точкам. Нанять отдельного человека для мониторинга репутации — дорого и нецелесообразно.

Задача

Автоматически собирать новые отзывы с 2ГИС и Яндекс.Карт, определять тональность с помощью AI и присылать алерт в Telegram при появлении негативного отзыва — в течение часа.

Решение

Написал парсер на Python + Playwright, который обходит страницы организаций на 2ГИС и Яндекс.Картах раз в час, извлекает новые отзывы и передаёт в GPT для анализа тональности.

Схема работы:

  • Playwright автоматически открывает страницы 4 точек на 2ГИС и Яндекс.Картах раз в час
  • Новые отзывы (ещё не встречавшиеся) извлекаются и сохраняются в PostgreSQL
  • GPT-4o mini классифицирует тональность: позитивный / нейтральный / негативный
  • При негативном — мгновенный алерт владельцу в Telegram с текстом отзыва и ссылкой
  • Еженедельный дайджест: сводка по каждой точке, средний рейтинг, динамика
  • Выгрузка в Google Sheets для ручного анализа менеджером по маркетингу

Технический стек

  • Python + Playwright — парсинг страниц 2ГИС и Яндекс.Карт
  • OpenAI API (GPT-4o mini) — классификация тональности
  • PostgreSQL — хранение отзывов и истории
  • Google Sheets API — еженедельная выгрузка
  • aiogram — Telegram-уведомления
  • APScheduler — запуск каждый час

Результат

За первую неделю система поймала 3 негативных отзыва. Игорь ответил на каждый в течение часа — объяснил ситуацию, предложил компенсацию. Один клиент после ответа исправил оценку с 1 на 4 звезды.

«Раньше я узнавал о плохом отзыве когда уже было поздно. Теперь я отвечаю быстрее конкурентов» — Игорь, владелец сети автомоек.
